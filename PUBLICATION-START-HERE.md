# VOIDSTING // First GitHub publication

This package is a self-contained **public-source candidate**, based on the verified v1.5.1 source bundle. The source code is preserved. New additions are the static `/docs` GitHub Pages homepage, privacy `.gitignore` and public README; the longer original README is preserved as `README-ENGINE-NOTES.md`. No private vaults or user research sessions are included.

1. Preview `docs/index.html` locally in a browser.
2. Manually review the files for any personal content you don't want public.
3. Create a **new public repository** named `VOIDSTING` in the `Hellfire13666` GitHub account. Do not choose a GitHub-generated initial README because this bundle supplies its own.
4. Upload the CONTENTS of this folder to the new repository. Do not upload this ZIP file as a single file; GitHub does not automatically unpack it.
5. In Settings > Pages, select `Deploy from a branch`, `main`, `/docs` and Save.
6. Only after deployment, `https://hellfire13666.github.io/VOIDSTING/` will become the static public home. This isn't the local live Cockpit; users still run VOIDSTING locally.
7. You can link the existing BLACKSWARM repo and sister homepage to it. Never mix their databases.
